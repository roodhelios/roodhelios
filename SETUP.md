# Setup

Everything visual in this profile is generated by a script here and committed
as a static SVG. No shared rendering service can take a section down.

## Layout

```
README.md
preview.html              open in a browser to see every asset, both themes
requirements.txt          pillow + numpy (banner only)
.github/workflows/
  profile.yml             daily: redraws radars + stats card, verifies, commits
assets/
  skills.json             self-rated scores -> radar
  langmix.json            language mix -> radar-langs
  *.svg                   generated, committed
scripts/
  radar.py                JSON -> radar SVG          (stdlib only)
  cards.py                GitHub GraphQL -> stats SVG (stdlib only)
  verify.py               catches overflow + geometry bugs
  banner/
    generate.py           photo -> terminal banner SVG
    prep.py               crops and masks the source photo
    profile.json          the SYSTEM.INFO rows
```

## First run

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

python scripts/radar.py assets/skills.json  --out assets --name radar
python scripts/radar.py assets/langmix.json --out assets --name radar-langs
python scripts/cards.py --mock --out assets      # or set GITHUB_TOKEN for real data
python scripts/verify.py
```

Then open `preview.html` in a browser.

## Changing things

**Radar scores** — edit `assets/skills.json` or `assets/langmix.json` and rerun
`radar.py`. The canvas resizes itself around the longest label, so you can add
axes or rename them without the text running off the edge. Keep the scores
defensible; they are a claim someone may ask you about in an interview.

**Banner text** — edit `scripts/banner/profile.json`. About 14 rows fit. Use `.`
rather than `·` as a separator: the SVG embeds no font, so it falls back to the
reader's system monospace and plain ASCII always aligns.

**Banner portrait** — the source photo is deliberately gitignored. Regenerate
locally:

```bash
python scripts/banner/prep.py        # crop + silhouette mask -> portrait.png
python scripts/banner/generate.py --photo portrait.png \
    --config scripts/banner/profile.json --out assets --gamma 1.15
```

`prep.py` holds a hand-traced silhouette for one specific photo. For a different
photo, run it through remove.bg and pass that PNG straight to `generate.py` —
the alpha channel is used as the mask, so no tracing is needed.

Tuning flags: `--points` for density, `--gamma` (above 1 thins mid-tones, below
1 fills them in), `--invert` for a dark subject on a light background.

## Cache busting

GitHub caches README images hard. After regenerating, bump the `?v=N` on the
affected `<picture>` paths in `README.md`, or you will keep seeing the old
version and think nothing happened.

## The stats card and tokens

`cards.py` uses the GraphQL API. In CI the built-in `GITHUB_TOKEN` is enough for
public stats — no secret to create, nothing to rotate.

Private contribution counts need a PAT with `repo` scope stored as a repository
secret, then `--include-private` added to the workflow step. Only do that if you
actually want private activity folded into the number, and use the narrowest
scope that works.

If the workflow fails at the commit step with a permissions error, set
**Settings → Actions → General → Workflow permissions** to *Read and write*.

## verify.py

Runs in CI before anything is committed. It estimates text widths from the
monospace advance ratio and checks that nothing overflows its panel or the
viewBox, and it re-derives every radar vertex from trigonometry to confirm the
polygon matches the JSON. It exists because a missing `text-anchor="end"` once
shipped a banner with every value running off the right edge.
